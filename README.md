# 🌹 Velour — Luxury Couture Dresses Website

A premium fashion landing page built with **HTML, CSS, JavaScript, Three.js, and GSAP**, designed for luxury couture brands. The website features elegant animations, custom SVG dress illustrations, interactive effects, and a modern responsive design.

## ✨ Features

* Premium luxury fashion UI/UX
* Fully responsive design
* Custom animated cursor
* Smooth scrolling navigation
* Glassmorphism navigation bar
* Interactive mobile menu
* GSAP scroll animations
* Three.js particle background
* SVG couture dress illustrations
* Product showcase section
* Brand story & philosophy section
* Contact form with submission feedback
* Elegant typography using Google Fonts

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Three.js
* GSAP
* ScrollTrigger
* Google Fonts
